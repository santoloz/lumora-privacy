Lumora Privacy Policy

Last updated: October 4, 2026

Lumora is a customizable new tab extension designed to provide search, clock, weather, news, radio, earthquake information, shortcuts and other useful tools in one browser start page.

Information We Store

Lumora may use Chrome's storage functionality to save settings selected by the user, such as language, theme, clock preferences, selected services, shortcuts and other customization options. These preferences are used to provide a consistent experience when opening a new tab.

External Services

Lumora may communicate with third-party services and APIs to provide features such as weather, news, radio, earthquake information, maps and search. The information returned by these services is used to display the requested feature inside Lumora.

Personal Data

Lumora does not sell personal data and does not use personal data for advertising purposes. Lumora does not intentionally collect sensitive personal information.

Data Sharing

Lumora does not sell or transfer user data to third parties for purposes unrelated to providing or operating the requested features. When an external service is used, information necessary for that service may be sent to the relevant provider according to that provider's own privacy policy.

Security

Lumora is designed to keep user preferences within the browser's storage where possible. No security method can guarantee absolute security, but Lumora does not intentionally collect or sell user data.

Children

Lumora is not designed to collect personal information from children.

Changes to This Policy

This privacy policy may be updated when Lumora's features or data practices change. The latest version will be published on this page.
